# hugo-photoalbum-theme

Hugo theme that adds tag- and date-filtered photo albums on top of
[`nicokaiser/hugo-theme-gallery`](https://github.com/nicokaiser/hugo-theme-gallery).
A "filtered" page collects matching images from anywhere in the site and renders
them as a single gallery, sharing the same image derivatives the underlying
gallery theme already produces — so a tag album is essentially a list of links,
not a second copy of every photo.

A working example with content fixtures and Playwright tests lives in
[`hugo-photoalbum-test`](https://github.com/cornelius/hugo-photoalbum-test).

## Installation

Add the theme as a Hugo module in `hugo.toml`:

```toml
[module]
  [[module.imports]]
    path = "github.com/cornelius/hugo-photoalbum-theme"
```

The base gallery theme is pulled in transitively.

## Tagging images

Tags live on image **resources** (not on pages), declared in the year/album
bundle's front matter:

```yaml
---
title: 2020
resources:
  - src: brandenburger-tor.jpg
    title: Brandenburger Tor
    params:
      tags:
        - Berlin
        - Cornelius
  - src: golden-gate.jpg
    params:
      tags:
        - Cornelius
---
```

Any string is allowed; tags are matched exactly (case-sensitive).

## Creating a filtered album

Add a page bundle with `type: filtered` and a `filter` block. Examples:

```yaml
# Tag-only album (e.g. content/people/cornelius/index.md)
---
type: filtered
title: Cornelius
params:
  filter:
    tag: Cornelius
---
```

```yaml
# Date-range album
---
type: filtered
title: London 2011
params:
  filter:
    start_date: 2011-10-15
    end_date: 2011-11-20
---
```

```yaml
# Combined: tag + date range
---
type: filtered
title: London 2020
params:
  filter:
    tag: London
    start_date: 2020-01-01
    end_date: 2020-12-31
---
```

## Parameters

All under `params:` in the page's front matter.

| Key | Type | Description |
|---|---|---|
| `filter.tag` | string | Include images whose `params.tags` contains this value. |
| `filter.start_date` | YYYY-MM-DD | Include images whose EXIF date is on or after this. |
| `filter.end_date` | YYYY-MM-DD | Include images whose EXIF date is on or before this. |
| `sort_by` | `Name` \| `Date` | Sort key. See defaults below. |
| `sort_order` | `asc` \| `desc` | Sort direction. Default `asc`. |

### Sort defaults and EXIF cost

`sort_by` defaults to **`Date`** when a date filter is set, **`Name`** otherwise.

This matters at scale. Sorting by `Date` forces the renderer to read EXIF
metadata for every candidate image. Sorting by `Name` reads no EXIF at all. On
a large site with many tag pages, the difference is significant — so the
default is to skip EXIF for tag-only pages.

If your filenames already encode dates (e.g. `19961216-IMG-14719.jpg`), `Name`
sort produces the same chronological order as `Date` for free. If they don't,
add `sort_by: Date` explicitly on the page to opt back in:

```yaml
params:
  filter:
    tag: Cornelius
  sort_by: Date
```

## Performance

The filtered gallery walks `Site.RegularPages × image resources` to find
matches. To keep this from running once per filtered page, the theme caches an
inverted index (`tag → []image`) via `partialCached "tag-index.html"`. The walk
runs exactly once per build regardless of how many tag pages exist; each
filtered page then does an O(1) lookup followed by per-match work proportional
to the number of matches.

Image derivatives (`fit 600x600` thumbnail, `fit 1600x1600` full) are produced
by Hugo's image processor and keyed by the SHA1 of the filter chain. Because
filtered pages link to derivatives generated by the originating year/album
page, they are reused — a tag album does not double disk usage. Verify after
your first tag page by grepping for an image's `_hu_<hash>` filename in both
the source-album HTML and the tag-album HTML; the hashes should match.

## Layouts provided

- `layouts/filtered/single.html` — page layout for `type: filtered` pages.
- `layouts/partials/filtered-gallery.html` — the gallery itself; can be called
  from any layout via `{{ partial "filtered-gallery.html" . }}` if you want to
  embed a filtered gallery inside another page type.
- `layouts/partials/tag-index.html` — internal; called via `partialCached`.

Everything else (header, navigation, page chrome, the regular non-filtered
gallery used for year/album pages) comes from `nicokaiser/hugo-theme-gallery`.
